# Быстрый запуск и сдача

1. Распакуй архив. Открой папку `notification-gateway`.
2. Для немедленного запуска нужен Java 17 или новее. Открой терминал в этой папке:

```sh
java -jar dist/notification-gateway-1.0.0.jar
```

3. Для работы с исходниками открой `pom.xml` в IntelliJ IDEA, выбери JDK 17, дождись загрузки Maven и запусти `Demo.main`.
4. Для тестов выполни `mvn test`. Для пересборки после изменений — `mvn package`; запускай обновлённый JAR из `target`.
5. Создай GitHub-репозиторий. Через Add file → Upload files загрузи содержимое папки: `src`, `docs`, `dist`, `pom.xml`, `README.md` и остальные файлы. Не загружай только ZIP.
6. Отправь ссылку на репозиторий в Moodle. При необходимости добавь своё имя и группу в README.
7. Перед защитой прочитай `docs/DEFENSE_RU.md`.

В проекте пять каналов, четыре типа уведомлений, UML, все обязательные сценарии и 25 успешно выполненных JUnit 5 тестов. Подробности проверки находятся в `docs/verification.txt`.

Репозиторий и отправку в Moodle нужно выполнить отдельно: архив подготовлен, но онлайн-публикация не выполнялась.
